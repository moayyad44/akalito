# زرع 20 وجبة سريعة + مكوناتها بقاعدة بيانات أكليتو

هالمجلد فيه سكربت جاهز يضيف 20 وجبة (برغر، شاورما، بيتزا، دجاج مقرمش، باستا، راب...) + 40 مكوّن + كل الوصفات الرابطة بينهم — دفعة وحدة.

## قبل ما تبلش (مرة وحدة بس)

1. لازم يكون عندك **Node.js** مثبّت على جهازك (لو مش متأكد، افتح Terminal/CMD واكتب `node -v` — لو ظهر رقم إصدار يعني موجود).
2. روح على [Firebase Console](https://console.firebase.google.com) → افتح مشروع أكليتو → ⚙️ **Project Settings** → تبويب **Service Accounts** → اضغط **Generate new private key** → بينزّل ملف JSON.
3. غيّر اسم الملف المنزّل إلى **`serviceAccountKey.json`** وحطّه بنفس هالمجلد (جنب `seed.js`).
   ⚠️ هاد الملف مهم جداً وسري — لا ترفعه لأي مكان عام (GitHub، واتساب، إلخ). خليه بس على جهازك.

## التشغيل

افتح Terminal/CMD جوا هالمجلد واكتب:

```bash
npm install
node seed.js
```

رح تشوف لوغ لايف بكل وجبة ومكوّن عم ينضاف. الطريقة **آمنة تماماً تعاد** (idempotent) — لو شغّلته مرتين بالغلط، بيتخطّى أي وجبة أو مكوّن موجود مسبقاً بنفس الاسم، وما رح يكرر شي.

## بعد ما يخلص

- افتح لوحة الأدمن (`akleto-admin.html`) → شاشة "الوجبات" أو "المنتجات" → رح تلاقي الـ20 وجبة الجديدة موجودة مباشرة (real-time، بدون Refresh حتى).
- **الصور حالياً بديلة (placeholder)** بألوان هوية أكليتو وعليها اسم كل وجبة — مو صور حقيقية. لما تجهز صور فعلية لأطباقك، بس افتح كل وجبة من لوحة الأدمن وبدّل حقل رابط الصورة (image_url) بصورتك — ما في داعي تشغّل السكربت تاني.
- الأسعار (`base_price`) والمقادير كلها **تقريبية** بناءً على السوق الأردني — عدّل أي شي حاب تظبطه من نفس شاشة تعديل الوجبة/المكوّن بلوحة الأدمن.

## شو بيضيف بالضبط

- **40 مكوّن** بمجموعة `ingredients` (نوع القياس، العبوة، السعر التقريبي)
- **20 وجبة** بمجموعة `meals` (تصنيف، صعوبة، وقت تحضير، سعر أساسي)
- **كل الوصفات** (أي مكوّن بأي كمية لكل وجبة) بمجموعة `meal_ingredients`
